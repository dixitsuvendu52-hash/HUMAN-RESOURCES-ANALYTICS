# HUMAN-RESOURCES-ANALYTICS
This project focuses on analyzing employee attrition trends using interactive Power BI dashboards. The goal is to help organizations understand the key factors influencing employee turnover and support data-driven HR decision-making.

 Key Insights Covered:
Overall attrition rate and employee distribution

Attrition analysis by department, job role, age group, gender, and education

Impact of salary, years at company, job satisfaction, and work-life balance

Identification of high-risk employee segments

🛠 Tools & Technologies:

Power BI – Data visualization & dashboard creation

Data Cleaning & Transformation – Power Query

DAX – Measures and calculated fields
 Features:
Interactive filters and slicers

Easy-to-understand visualizations (charts, KPIs, tables)

Business-focused insights for HR teams and management
