🧠 Employee Attrition Dashboard – Power BI







This repository contains a Power BI dashboard project analyzing employee attrition and the key factors influencing it. The report uses Power Query for data transformation and DAX for advanced analytics.



📊 Project Overview







The Employee Attrition Dashboard helps HR and management teams understand:



Which departments have the highest attrition rates

Key factors influencing employee turnover (e.g., age, salary, job role, years at company)

Trends in attrition over time

Comparison between current and past periods



🛠️ Tools \& Technologies



Power BI Desktop – Data visualization and modeling

Power Query Editor – Data cleaning and transformation

DAX (Data Analysis Expressions) – Calculated columns and measures

Excel / CSV – Source data



📁 Repository Structure

Employee\_Attrition\_Dashboard.pbix   # Main Power BI project file

data/                               # (Optional) Example datasets

docs/                               # Screenshots, diagrams, or visuals

README.md                           # Project documentation





🚀 How to Use



Download the .pbix file from this repository.

Open it in Power BI Desktop (latest version recommended).

Refresh the data or connect it to your organization’s dataset.

Explore insights through interactive visuals and filters.



🔍 Insights Delivered



Overall Attrition Rate

Attrition by Department

Attrition by Job Role

Impact of Salary, Tenure, and Age

KPI Cards for HR Decision Support
